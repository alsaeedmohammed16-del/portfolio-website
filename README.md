# Mohammad Alsaeed portfolio

A deliberately simple, responsive one-page portfolio built with plain HTML, CSS and a tiny amount of JavaScript. The content comes from your CV, with no invented experience, metrics or project links.

## Before publishing

- Add live GitHub links to individual projects once they are ready. The current project descriptions deliberately do not pretend that unfinished work is deployed.
- Update the internship year if needed.
- Open `index.html` in a browser to preview it locally.

It can be deployed directly to GitHub Pages, Netlify, or Vercel—no build step required.
